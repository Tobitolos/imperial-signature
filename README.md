# Imperial Signature

Nigerian fashion and fragrance storefront: house unisex clothing plus curated fragrances from other brands.

This is a TypeScript Next.js App Router preview. The catalog, prices, bank account and contact details are **samples / placeholders** until live inventory and official channels are published.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checkout (v1)

Bank transfer only. Customers place an order, receive an `IS-YYYYMMDD-XXXX` reference, transfer the disclosed total, and the order is confirmed only after Imperial Signature verifies payment. The site does not collect cards, PINs or OTPs.
